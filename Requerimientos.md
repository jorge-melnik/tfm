# Especificación de requerimientos

## Gestión de usuarios y perfiles (GUP)

- RF-GUP-01: El sistema debe permitir al usuario consumidor registrarse en nuestra página con nombres, apellidos, dirección, contraseña, email y celular.
- RF-GUP-02: El sistema debe permitir al usuario vendedor registrarse en nuestra página con nombres, apellidos, dirección, contraseña, email, celular, ubicación, foto y descripción.
- RF-GUP-03: El sistema debe permitir al usuario el registro con Google.
- RF-GUP-04: El sistema debe permitir al usuario el registro con Facebook.
- RF-GUP-05: El sistema debe permitir al usuario iniciar sesión con Google y el email previamente registrado.
- RF-GUP-06: El sistema debe permitir al usuario iniciar sesión con Facebook y el email previamente registrado.
- RF-GUP-07: El sistema debe permitir al usuario iniciar sesión con WhatsApp y el celular previamente registrado.
- RF-GUP-08: El proveedor podrá gestionar sus perfil con nombres, apellidos, dirección, contraseña, email, celular, ubicación, foto y descripción.

## Panel del productor (PP)

- RF-PP-01: El sistema debe permitir al usuario gestionar su catálogo de productos ingresando nombre del producto, descripción, precio, cantidad disponible y entre 1 y 5 fotos del producto.
- RF-PP-02: El sistema debe gestionar el stock del producto para cada venta realizada.
- RF-PP-03: El sistema debe gestionar el stock de los productos para cada venta en proceso de pago. (Descuenta stock, si se confirma el pago listo, sino se vuelve a sumar el stock).
- RF-PP-04: El sistema debe permitir al vendedor gestionar los pedidos recibidos.
- RF-PP-05: El sistema debe proporcionar al vendedor un mecanismo para ver el historial de ventas.
- RF-PP-06: El sistema debe proporcionar al vendedor un mecanismo para ver el historial de pagos recibidos.
- RF-PP-07: El sistema debe permitir al vendedor gestionar los mensajes recibidos.

## Panel del consumidor

- RF-PC-01: El sistema debe permitir al consumidor explorar productos en base a la catergoría seleccionada y su ubicación.
- RF-PC-02: El sistema debe permitir al consumidor gestionar su carrito de compras.
- RF-PC-03: El sistema debe permitir al consumidor finalizar una compra con los productos del carrito.
- RF-PC-04: Al finalizar una compra el sistema debe permitir al consumidor seleccionar entre los siguientes medios de pago: ebrou, abitab, tarjeta.
- RF-PC-05: El sistema debe permitir al consumidor visualizar los datos del productor en una compra finalizada. (O SIEMPRE?)
- RF-PC-06: El sistema debe proporcionar al consumidor un mecanismo para consultar el historial de compras.
- RF-PC-07: El sistema debe permitir al consumidor contactar al productor de una compra finalizada.
